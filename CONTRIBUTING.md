# Contributing to Tuling Creative Hub

## Workflow
1. Create a feature or fix branch from `main` (e.g., `feat/admission-workflow` or `fix/attendance-sync`).
2. Keep changes scoped to the task and follow project linting, type-checking, and test conventions.
3. Run read-only checks and dry runs before testing database migrations or data reconciliation scripts.
4. Open a Pull Request using the PR template and verify checks pass before merging.
