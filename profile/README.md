# Tuling Creative Hub

Software and services for schools, colleges, universities, and businesses.

## Core Offerings
- **Tuling Campus Solution**: Modular education operating system where each module (Admission CRM, Admission Management, SIS, LMS, Financials & Tally Connector, Library & Gate Apps, Institutional HCM, Campus Ops, Alumni) works independently or together, with custom workflows and DPDP data governance.
- **Tuling Corporate HRMS**: Attendance, leave, statutory payroll, hiring, performance, POSH, and DPDP data governance for organizations.
- **Data Governance**: Dedicated Data Governance Dashboard for consent tracking, turning-18 renewal workflows, and data erasure controls.
