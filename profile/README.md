# Tuling Creative Hub

Modular software and digital systems for schools, colleges, universities, and organizations.

## What We Build
- **Tuling Campus Solution**: Modular education operating system where each module—Admission CRM, Admission Management, Student Information System (SIS), Learning Management System (LMS), Financials & Tally Connector, Library & Gate Apps, Institutional HCM, Campus Ops, and Alumni—works independently or together, with custom workflows and DPDP data governance.
- **Tuling Corporate HRMS**: Workforce attendance, leave, statutory payroll, hiring, performance, POSH workflows, and DPDP data governance for organizations.
- **Data Governance**: Dedicated Data Governance Dashboard supporting student and parent consent tracking, turning-18 consent renewal workflows, and data erasure controls.
